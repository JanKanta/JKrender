JKrender - install

1. Copy the whole JKrender folder into %USERPROFILE%\.nuke\
2. Add this line to %USERPROFILE%\.nuke\init.py (create the file if it is not there):

       nuke.pluginAddPath("./JKrender")

3. Restart Nuke. On the first start, JKrender asks to download numpy and OpenEXR
   for the EXR preview (about 15 MB). They download in the background into JKrender\lib.
   If you say No, rendering still works, only without the EXR preview, and you are not asked again.
   To be asked again, delete JKrender\lib\DECLINED.

Use: select a Write (or a Group with Writes) and choose JKrender > Render Selected Write(s), or press Ctrl+Alt+R.

The window runs in Nuke's own Python, so nothing else needs installing.
Made for Nuke 16 on Windows.

Optional: for MOV details and the MOV player, install ffmpeg:  winget install ffmpeg

Each render's logs, script copy and job file are in the JKrender\log folder.
Uninstall: delete the line from init.py and the JKrender folder.
